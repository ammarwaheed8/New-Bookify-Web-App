# Bookify

A complete hotel-booking web app: vanilla HTML/CSS/JS frontend, PHP 8 + PDO backend, SQLite storage.
No frameworks, no build tools, no paid services.

## Prerequisites
- PHP 8.0+ with `pdo_sqlite` (bundled by default) and `mbstring`
- A modern browser
- Optional: a mail transport for `mail()` (not required locally)
